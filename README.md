# Financial Management API

A RESTful API for managing financial reminders and transactions. Built with Spring Boot and following the principles of Hexagonal Architecture.

## Tech Stack

-   **Java 17**
-   **Spring Boot**
    -   **Spring Web**
    -   **Spring Security**
    -   **Spring Data JPA** & **Hibernate**
-   **PostgreSQL**
-   **Redis**
-   **Docker & Docker Compose**
-   **JWT (Java Web Token)**
-   **Maven**

## Running the Project

This project is fully containerized. For detailed instructions on how to run the application, please see the [**HELPME.md**](./HELPME.md) file.
